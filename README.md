# SoundBridge Speech and Hearing Clinic — Official Website

A luxury, interactive medical-tech web experience for **SoundBridge Speech and Hearing Clinic**, located in Nagarbhavi, Bengaluru.

---

## 🌟 Key Features

- **3D Hero Experience**: Custom Three.js interactive 3D anatomical inner-ear and cochlea sculpture with resonant acoustic wave rings and cinematic mouse tracking.
- **3D Device Explorer**: Interactive 3D Receiver-In-Canal (RIC) hearing aid model with 360° drag-to-rotate, auto-rotation, and interactive hotspot pins.
- **Acoustic Resonance Visualizer**: Real-time canvas waveform animation illustrating sound transmission and emotional connection.
- **Therapeutic Ambient Sound Engine**: Built-in harmonic sound generator utilizing the Web Audio API for an immersive clinical experience.
- **Scroll-Triggered Animated Counters**: Live ease-out metric counting (`5.0 ★`, `8+ Years`, `100%`).
- **Clinical Services Drawer**: 8 expandable horizontal service panels with waveform graphs and direct appointment integration.
- **High-Conversion Appointment Modal**: Accessible booking flow with real-time field validation, date picker, and confirmation animation.
- **Fully Responsive**: Crafted with mobile-first CSS architecture for phones, tablets, and 4K displays.

## 🚀 Quick Start (Local Development)

Open `index.html` directly in any web browser, or run a local static server:

```bash
# Using Node.js
node server.js

# Or using Python
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy to GitHub Pages (Free)

1. Push this repository to GitHub.
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
